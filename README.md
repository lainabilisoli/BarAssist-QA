# BarAssist QA Portfolio

BarAssist is a mobile cocktail recipe application designed for everyone from beginners to professional bartenders. Its voice search allows bartenders to retrieve recipes hands-free while preparing drinks, making it easy to respond to customer orders without interrupting their workflow.

This repository showcases the complete QA process for BarAssist, including test planning, requirements analysis, test case design, defect reporting, test execution, regression testing, and the final test summary.

This project demonstrates practical software testing skills through structured planning, test design, execution, defect reporting, and documentation based on ISTQB Foundation Level principles.
